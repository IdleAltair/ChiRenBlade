# ChiRen Blade 1.0

## 核心功能与「仁慈龙卷」特色

- **拼刀奖励与杀气结算**：炽刃拼刀成功后，接下来 6 次重攻击免杀气，平时重攻击杀气永久减半（`HeavyCostScale = 0.5`），同时刀身附火 5 秒、获得 1.2 秒无敌，每 3 次拼刀触发原生 Break 破防打断（维持 1.2 秒压制）。由于底层重攻击扣费无法通过反射或 Hook 直接拦截，杀气减免通过游戏原生的「杀气结算段」（棕色待结算段）补回 `BaseValue`：杀气条会来回涨跌，且在连续消耗杀气的动作链中需等到可恢复杀气的时刻（如连招结束、闪避或轻重击穿插出轻击时）补回。
- **风回云卷（可正常致死）**：普通拼刀累积 1~6 层龙卷层数，刀劲三档释放「风回云卷」（`LB+Y`）享受 1~6 倍伤害加成、2.5 秒无敌与 15 秒火焰延长，可直接斩杀敌人。
- **切刀 GP「仁慈火龙卷」与敌人缠身火（留 1 血特色）**：切出炽刃起手自带 0.5 秒（15 帧）原生弹反窗口，切武保留刀劲层数。切刀 GP 成功时自动甩出「处决同款」黑伤火龙卷追踪敌人，造成多段范围伤害并点燃敌人使其全身着火约 5 秒（`EnemyBurnVisual = true`）。为避免直接改写 0 血导致 Boss 跳过原生死亡/转阶段事件而卡死（且其绑定的原生燃烧 DoT 底层同样走非致死伤害计算），切刀 GP 火龙卷伤害封顶保留 1 点生命值，将最后一击交还给持刀者完成。

> 「烈焰摧锋，留命一线。龙卷可破敌势、灼其筋骨，却不取最后一息；胜负已分，生死仍由侠者落刃。」——防御龙（GPT）

## 发布配置

发布版默认关闭开发探针、高频逐击日志、致死研究和一次拼刀直达满刀劲的捷径（`TornadoEasyCast = false`）。敌人燃烧视觉使用独立挂载的 Niagara 组件，不修改游戏的池化组件；当 UE4SS 无法读取敌方 GE 句柄时，自动回退为与燃烧 DoT 一致的 5 秒固定生命周期。
